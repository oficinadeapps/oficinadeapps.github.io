# Oficina de Apps

Site público e políticas de privacidade dos apps e jogos da **Oficina de Apps**.
Tudo funciona offline, sem anúncios, sem cadastro e sem coleta de dados.

**Site:** https://oficinadeapps.github.io/

## Estrutura

```
index.html          # home: seção "Jogos infantis" + seção "Apps"
<app>/index.html    # página do app
<app>/privacy.html  # política de privacidade (URL colada nas lojas)
```

## Site antigo (jogos-infantis.github.io)

Os quatro jogos ficavam em `jogos-infantis.github.io` e essas URLs já estão
coladas nas lojas. O repo `Jogos-Infantis/Jogos-Infantis.github.io` continua no
ar **só com redirects** para as páginas correspondentes aqui — não apagar, não
arquivar. As listings podem ser atualizadas para as URLs novas sem pressa.

## O que os apps NÃO fazem

- ❌ Não pedem internet (todos funcionam offline)
- ❌ Não pedem cadastro nem login
- ❌ Não têm anúncios nem compras dentro do app
- ❌ Não coletam nenhum dado
